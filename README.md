A program that writes one sentence to `/output/entry.txt` for make.fun's "Five Seconds to Explain the Glass" bounty: a house cat's defence in the five seconds after knocking a glass off the table, in the cat's own voice. The angle is territorial eviction, not physics — the glass sat in the cat's sunbeam spot and stared, so the cat evicted it, with zero remorse. No apology, no confession, and none of the brief's named cliches (gravity, slippery edge, it-was-already-falling).

> It sat in my sunbeam, in my spot, staring at me, so I evicted it — and I'd do it again before breakfast.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (104 characters, inside the 1–200 gate), validates the gate before writing, and reads the file back to verify it landed byte-identical.
